1 Thusimbu.
25.
David le a sepai jalamkai ten Asaph, Heman chule Jeduthun insungmi chu Kipana Thupha sapphong toh thoa semjang gin ngai, tumging chule khutbeh la lamkai din alhengdoh tauve. Hiche hi amin ule anatoh u ahi: 
Asaph chapa te Zaccur, Joseph, Nethaniah chule Asarelah ahiuve. Amahon apau, Asaph, lamhilna dungjuiya na atoh u ahin, leng thusah dungjuiya Pathen thu seiphongna chu amaho kin ahi. 
Jeduthun chapa te Gedaliah, Zeri, Jeshaiah, Shimei, Hashabiah chule Mattithah, abonun mi gup ahiuve. Amaho hin apau Jeduthun makainan semjang gin ngei, thangvah le vahchoi toh thon Pathen thu sapphongna aneiyun ahi. 
Heman chapa te chu Bukkiah, Mattaniah, Uzziel, Shubael, Jerimoth, Hananiah, Hanani, Eliathah, Giddalti, Romamti-ezer, Joshbekashah, Mallothi, Hothir chule Mahazioth ahiuve. 
Hiche ho jouse hi Hemam chapa te ahiuvin, lengpa mitva neiya pang Heman hin Pakaiya kon'in chapa som le li toh chanu thum ahing e. 
Hiche miho jouse hin apauvin alamhil dungjui uva tumging thei ho Pakai insunga asem'u ahi. Amopoh nau hi Pathen ina tumging thei, selangdah gin ngei, semjang sai chule khutbeh ho ajaovin ahi. Chule ijakaiyin, Asaph, Jeduthun chule Heman jong lengpa toh aki thukop jing uve. 
Amaho insung hi Pakai vahchoi na mun a tumging sai ding mong a hung kitillu ahi. Abonchauvin tumging sai thei cheh mi 288 alhing uve. 
Mi hichengse hi teh le khang hihen jilkung le simlai umlouvin athepna cheh uva apang un chuleh vang kibangin akisan cheh uve. 
Vang kisan masapen chu Asaph phung'a Joseph le achapa te chule akinaipi som le ni ho chunga achu'n ahi. Vang kisan anina chu Gedaliah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan athumna chu Zaccur le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan alina chu Zeri le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan angana chu Nethaniah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan agupna chu Bukkiah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan asagena chu Asarelah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan agietna chu Jeshaiah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan akona chu Mattaniah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan asomna chu Shimei le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le khatna chu Uzziel le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le nina chu Hashabiah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le thumna chu Shubael le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le lina chu Mattithiah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le ngana chu Jerimoth le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le gupna chu Hananiah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le sagena chu Joshbekashah le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le gietna chu Hanani le achapa te chule akinaipi som le ni ho chunga achu'n ahi. 
Vang kisan som le kona chu Mallothi le achapa te chule akinaipi som le ni ho chunga achu'n ahi.

Vang kisan somni le khatna chu Hothir le achapa te chule akinaipi som le ni ho chunga achu'n ahi.
